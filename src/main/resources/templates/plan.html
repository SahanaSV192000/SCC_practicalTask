5-Day DevOps Training Plan

Learn the complete delivery flow from GitHub source control to production operations.

Day Skills to Build Focus Area Topics to Cover Practical Task
Day 1 Understand DevOps workflows and source control practices DevOps Foundations and Git DevOps lifecycle, CI/CD overview, Git branching, pull requests, code review, release flow Create a Git repository, use feature branches, raise a pull request, and merge using review rules.
Day 2 Build automated validation pipelines CI Pipeline and Build Automation CI concepts, build stages, unit testing, linting, artifacts, pipeline triggers, quality gates Create a CI pipeline that runs linting, unit tests, and generates a build artifact.
Day 3 Package applications consistently Docker and Containers Dockerfile, image layers, container lifecycle, image tagging, registries, environment variables, container security Dockerize the Java application and run it locally with the required configuration.
Day 4 Deploy and manage applications in Kubernetes Kubernetes and Deployment Pods, deployments, services, config maps, secrets, namespaces, rolling updates, rollback, health checks Deploy the containerized application to Kubernetes and expose it through a service.
Day 5 Operate and maintain production-like systems IaC, Monitoring, Security, and Troubleshooting Terraform basics, cloud infrastructure, logging, metrics, alerting, secrets management, incident handling, RCA Provision basic infrastructure, add monitoring, simulate failure, troubleshoot, and roll back.
