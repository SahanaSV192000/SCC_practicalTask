Practical Task: Build and Deploy a Simple Application

Create a complete delivery flow using GitHub, Jenkins, Docker, and Kubernetes.

Assignment Instructions

  1. Create a GitHub repository for the Java application. Use a feature branch and create a pull request.
  2. Add a Jenkins CI pipeline that checks out the code, runs tests, packages the application, and produces a JAR artifact.
  3. Create a Dockerfile and build a container image for the Java application.
  4. Deploy the Docker image to a local Kubernetes cluster such as Minikube or Docker Desktop Kubernetes.
  5. Add basic health checks so Kubernetes can determine whether the application is ready and running.
  6. Simulate a failed deployment, detect the failure, and roll back to the last working version.
  7. Write a short incident note covering:
    • What failed?
    • How was the failure detected?
    • How was it fixed or rolled back?
    • What could prevent the issue in the future?

Failure Simulation

To simulate a failed deployment, update the Kubernetes deployment to use an invalid Docker image tag. Then observe the failure using:

kubectl get pods
kubectl describe pod POD_NAME
kubectl get events
kubectl rollout status deployment/scc-practical-task

After collecting evidence, roll back:

kubectl rollout undo deployment/scc-practical-task
kubectl rollout status deployment/scc-practical-task
